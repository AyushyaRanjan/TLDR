# Changelog

## 0.1.0

First public release.

- Standard mode: 30-second summary, 3-minute explanation, and page-grouped notes.
- Goal mode: relevance filter, targeted sections, and grounding checks.
- Typer CLI and Streamlit UI.
- Ollama Modelfile (`tldr-qwen`) with an 8192 context window.
- Tests against a fake LLM client, plus an optional live eval.
